# Machine-Learning-LogisticRegression-End-To-End-ML-Project

## Machine Learning Engineer & Flask Developer | Specialized in building end-to-end predictive pipelines with Scikit-Learn and deploying via REST APIs.

### A full-stack Machine Learning application that predicts consumer purchasing behavior using Logistic Regression and GridSearchCV. Features a clean Flask web interface and a robust preprocessing pipeline.

## Social Network Ads: Predictive Purchase System
This repository contains a complete end-to-end machine learning solution designed to predict whether a user will purchase a product based on social media advertisement data.

# 🚀 Key Features
Automated Preprocessing: Handles categorical mapping and feature scaling using a StandardScaler pipeline to ensure mathematical consistency between training and production.

## Optimized Modeling: 
Utilizes GridSearchCV to tune a Logistic Regression model across multiple hyperparameters (Penalty, C-values, and Solvers), achieving optimal accuracy.

## Web Deployment: 
A production-ready Flask Application that loads pickled model artifacts to provide real-time predictions through a user-friendly interface.

## Data Insights: 
Comprehensive EDA including correlation heatmaps and distribution analysis using Seaborn and Matplotlib.

# 🛠 Tech Stack
Languages: Python 3.12

ML Frameworks: Scikit-Learn (LogisticRegression, GridSearchCV, Preprocessing)

Data Science: Pandas, NumPy

Visualization: Seaborn, Matplotlib

Web Framework: Flask

Serialization: Pickle
